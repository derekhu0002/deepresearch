# 讲解视频《ArchGraph · Agent 组织与协作》制作方案与分镜脚本

需求提出者：视频制作Leader 需求委托（Actor: video-leader-001）
制作执行：视频制作（video-producer-001，dashscope-video-generator Skill / SVG→PNG 幻灯片 + cosyvoice TTS 旁白 + ffmpeg 组装）
验收执行：视频审核（video-reviewer-001，qwen3-vl-visual-inspection Skill → `bl vision describe`，qwen3-vl-plus）

## 一、制作解析

| 项 | 结论 | 理由 |
|---|---|---|
| 主题 | ArchGraph 的 Agent 组织：ACTOR 能力 / 协作关系 / 业务流程 | 讲解内容源自意图图谱 `AgentOrganization`(1962) 组织结构与团队视图 |
| 目标时长 | 约 2.5 分钟（≈140s） | 9 个场景旁白累加 |
| 分辨率 | 1080P 横屏（1920×1080） | 讲解/演示型视频标准 16:9 画幅，文本与关系图清晰 |
| 风格 | 深色主题信息图（卡片 + 关系图 + 流程图） | 讲解类视频以信息准确清晰为第一优先；SVG 渲染保证中文文本锐利无幻觉 |
| 载体 | 幻灯片（SVG→PNG）+ TTS 旁白 + ffmpeg 拼接 | 文本/关系/流程必须精确，避免文生图/文生视频的文本渲染幻觉 |
| 旁白音色 | cosyvoice-v3-flash `longxiaochun_v3`（知性积极女） | 讲解旁白风格，与《换一换》片尾旁白一致 |

## 二、分镜脚本（9 场景）

| # | 场景 | 画面要点 | 旁白（TTS 文本） | 时长 |
|---|---|---|---|---|
| S1 | 开场标题 | 大标题「ArchGraph · Agent 组织与协作」+ 副标题 + 日期 | 欢迎来到 ArchGraph 的 Agent 组织讲解。本视频将梳理意图图谱中登记的四个业务角色——他们的能力、协作关系，以及被卷入的主要业务流程。 | ~13s |
| S2 | 团队总览 | AgentOrganization 树：媒体创作团队 / 视频制作团队 → 4 个 Actor | 在 Agent 组织中，共登记四个业务角色，分属两个团队：媒体创作团队由媒体艺术家负责图片与视频创作；视频制作团队由视频制作 Leader 统筹，带领视频制作与视频审核两个角色完成视频的生成与验收。 | ~18s |
| S3 | 媒体艺术家 | 能力卡：图像生成 / 视觉验收 / 视频生成 | 首先看媒体艺术家。它负责图片与视频的创作执行，通过 DashScope 原生图像接口生成写实图片，使用 qwen3 视觉模型验收画面内容与角色标注定位，并可调用文生视频接口生成视频片段。 | ~18s |
| S4 | 视频制作Leader | 编排卡：接收需求→指派制作→指派审核→交付 | 视频制作 Leader 是整个视频团队的枢纽。它接收视频制作需求，统筹编排流程：将生成任务指派给视频制作，将验收任务指派给视频审核，审核通过后向需求提出者交付最终视频，并对交付质量负最终责任。 | ~19s |
| S5 | 视频制作 | 能力卡：HappyHorse / 万相、异步轮询下载 | 视频制作角色负责实际生成视频。它调用 DashScope 的视频生成模型，提交异步合成任务，轮询任务状态，成功后立即下载 MP4，因为视频链接只有二十四小时有效。 | ~16s |
| S6 | 视频审核 | 能力卡：抽帧 + qwen3-vl-plus 逐条核对 | 视频审核角色负责把关质量。它抽取生成视频的关键帧，用 qwen3 视觉模型逐条核对：画面元素是否完整、内容是否符合主题、时长分辨率是否达标、标注是否准确无遮挡，并输出符合或不符合的结论。 | ~18s |
| S7 | 协作关系图 | 关系图：Leader--Aggregation-->制作/审核；媒体艺术家--Assignment-->图片视频生成 Role--uses-->3 Skill | 从协作关系看：媒体艺术家通过指派关系承担图片视频生成角色，使用图像生成、视觉验收、视频生成三项技能；视频制作 Leader 通过聚合关系归属视频制作与视频审核两个角色，它们分别使用视频生成与视觉验收技能。 | ~20s |
| S8 | 业务流程 | 流程图：需求→解析→指派制作→指派审核→交付/返工 | 这形成了视频制作的核心流程：需求提出者提出需求，Leader 解析后指派视频制作生成，再指派视频审核验收；不通过则返工重制，通过后由 Leader 交付最终视频文件。 | ~17s |
| S9 | 结尾 | 总结 4 角色 + 谢谢观看 | 以上就是 ArchGraph 的 Agent 组织梳理：四个业务角色、明确的能力边界与协作关系，共同支撑媒体与视频的高效交付。感谢观看！ | ~14s |

合计约 **153s ≈ 2.5 分钟**。

## 三、制作流程

1. **幻灯片**：`scripts/generate-actor-explainer-slides.js` 生成 9 张 SVG（深色主题 1920×1080）→ sharp 转 PNG。
2. **旁白**：`bl speech synthesize`（cosyvoice-v3-flash / longxiaochun_v3）逐场景生成 WAV。
3. **组装**：ffmpeg 每场景「图 + 音」合成 MP4（淡入淡出），concat 拼接为 `actor-explainer.mp4`。
4. **验收**：qwen3-vl-plus 抽帧核对每场景画面元素与文本准确性。
