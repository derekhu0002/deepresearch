# 讲解视频《deepresearch · Agent 组织与协作》制作方案与分镜脚本

需求提出者：视频制作Leader 需求委托（Actor: video-leader-001）
制作执行：视频制作（video-producer-001，SVG→PNG 幻灯片 + cosyvoice TTS 旁白 + ffmpeg 组装）
验收执行：视频审核（video-reviewer-001，qwen3-vl-visual-inspection Skill → `bl vision describe`，qwen3-vl-plus）

## 一、制作解析

| 项 | 结论 | 理由 |
|---|---|---|
| 主题 | deepresearch 的全部 Agent：研究智能体（单/多智能体）+ 媒体/视频生产 Actor | 覆盖意图图谱全部 Agent（用户确认范围） |
| 目标时长 | 约 3.5–4 分钟 | 13 场景旁白累加 |
| 分辨率 | 1080P 横屏（1920×1080） | 讲解/演示型视频标准 16:9 画幅 |
| 风格 | 深色主题信息图（卡片 + 关系图 + 流程图） | 讲解类视频以信息准确清晰为第一优先；SVG 渲染保证中文文本锐利 |
| 旁白音色 | cosyvoice-v3-flash `longxiaochun_v3`（知性积极女） | 讲解旁白风格 |

## 二、分镜脚本（13 场景）

| # | 场景 | 画面要点 | 旁白（TTS 文本） | 时长 |
|---|---|---|---|---|
| S1 | 开场标题 | 大标题「deepresearch · Agent 组织与协作」+ 两大 Agent 体系 | 欢迎来到 deepresearch 的 Agent 组织讲解。本视频将梳理全部智能体的能力、协作关系，与被卷入的主要业务流程——包括研究智能体，以及媒体与视频生产 Actor。 | ~15s |
| S2 | Agent 全景 | gpt-researcher Agent 行为模型（单/多智能体）+ AgentOrganization（媒体/视频） | 在 deepresearch 的意图图谱中，Agent 体系分为两大块：第一块是 gpt-researcher Agent 行为模型，包含单智能体系统 GPTResearcher，与多智能体协作系统；第二块是 AgentOrganization 媒体与视频生产组织，包含媒体艺术家，以及视频制作 Leader 带领的制作与审核角色。 | ~22s |
| S3 | 单智能体系统 GPTResearcher | 行为函数卡 + 数据对象 + 报告流程 | 先看单智能体系统 GPTResearcher。它完成从查询到报告的全流程：选择智能体角色、规划研究子查询、按来源执行检索、策展来源可信度，最终撰写报告；对复杂问题，还能以广度乘以深度递归下钻研究。 | ~21s |
| S4 | 多智能体协作团队总览 | 10 角色网格 + LangGraph StateGraph 编排 | 多智能体协作系统则组建了一支研究团队，共十个角色，由 LangGraph 状态图统一编排：主编、编辑、研究员、写手、评审、修订、事实核查、人工评审、图表与发布，各司其职。 | ~18s |
| S5 | 编排与规划 | ChiefEditorAgent + EditorAgent | 主编 ChiefEditorAgent 构建状态图并编排整个团队；编辑 EditorAgent 规划章节大纲，并为各章节并行启动研究与撰写。 | ~14s |
| S6 | 研究与撰写 | ResearchAgent + WriterAgent | 研究员 ResearchAgent 包装了单智能体 GPTResearcher，执行初始研究与章节深度研究；写手 WriterAgent 负责撰写章节内容。 | ~13s |
| S7 | 质量保障 | ReviewerAgent→ReviserAgent 循环 + FactCheckerAgent | 质量由三道关卡保障：评审 ReviewerAgent 按规范评审草稿，修订 ReviserAgent 按意见修改，二者循环直到接受；事实核查 FactCheckerAgent 再核对事实与幻觉。 | ~17s |
| S8 | 人工与呈现 | HumanAgent + VisualizerAgent + PublisherAgent | 人工在环环节由 HumanAgent 评审研究计划；视觉化 VisualizerAgent 生成图表；最后发布 PublisherAgent 按 PDF、Word 或 Markdown 输出交付物。 | ~14s |
| S9 | 多智能体工作流 | LangGraph 工作流流程图 + 章节子工作流 | 多智能体的 LangGraph 工作流依次经过：初始研究、规划、人工评审计划、并行章节研究、撰写、事实核查、图表生成、发布。每一章的草稿还会走研究、评审、修订的循环。 | ~18s |
| S10 | 媒体艺术家 | 三能力卡 + 团队归属 | 再看媒体与视频生产 Actor。媒体艺术家负责图片与视频创作：通过 DashScope 生成写实图片，用 qwen3 视觉模型验收画面，也可调用文生视频接口。 | ~13s |
| S11 | 视频团队 | Leader + 视频制作 + 视频审核 能力卡 | 视频制作 Leader 统筹团队：指派视频制作调用 DashScope 视频模型生成 MP4，指派视频审核用 qwen3 视觉模型抽帧核对，通过后交付，不通过返工。 | ~15s |
| S12 | 生产协作与流程 | 协作关系（Assignment/Aggregation/uses）+ 媒体创作/视频制作流程 | 从协作看：媒体艺术家通过指派关系承担图片视频生成角色；Leader 通过聚合关系归属视频制作与视频审核；生产流程覆盖需求、生成、视觉验收、交付的闭环。 | ~18s |
| S13 | 结尾 | 全部智能体总结 + 谢谢观看 | 以上就是 deepresearch 的全部 Agent 梳理：研究智能体负责证据型深度研究，媒体与视频生产 Actor 负责成果的可视化呈现，能力边界清晰、协作高效。感谢观看！ | ~15s |

合计约 **213s ≈ 3.5 分钟**。

## 三、制作流程

1. **幻灯片**：`scripts/generate-actor-explainer-slides.js` 生成 13 张 SVG（深色主题 1920×1080）→ sharp 转 PNG。
2. **旁白**：`bl speech synthesize`（cosyvoice-v3-flash / longxiaochun_v3）逐场景生成 WAV。
3. **组装**：ffmpeg 每场景「图 + 音」合成 MP4（淡入淡出），concat 拼接为 `actor-explainer.mp4`。
4. **验收**：qwen3-vl-plus 抽帧核对每场景画面元素与文本准确性。
