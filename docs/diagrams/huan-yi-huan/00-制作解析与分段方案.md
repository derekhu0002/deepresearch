## 一、制作解析结论

| 项 | 结论 | 理由 |
|---|---|---|
| 主题 | 亲子关系 / 父子角色互换奇幻短剧《换一换》 | 剧本题材为亲子关系 + 奇幻互换，共 6 场约 3 分钟 |
| 目标时长 | 约 3 分钟（180 秒） | 需求约定；实际按 6 场分段生成，各段累加 |
| 分辨率 | 1080P（1920×1080 逻辑、输出 1080×1920 竖屏） | DashScope HappyHorse happyhorse-1.1-t2v 支持 1080P |
| 宽高比 | 9:16（竖屏） | 目标平台为抖音/快手/视频号/小红书等竖屏短视频平台；剧本大量 POV 主观镜头、玩具/床底/杯内微型机位、低角度仰拍在竖屏构图下情绪更聚焦 |
| 风格 | 写实卡通（Pixar 风格 3D 动画渲染） | 剧本含 360° 环绕、角色互换、镜像、白闪等奇幻元素，写实卡通能自然承载"互换"设定，且跨片段保持角色一致性更可控；避免真人肖像的伦理与一致性风险 |
| 适用平台/用途 | 抖音 / 快手 / 微信视频号 / 小红书 亲子类剧情短视频 | 竖屏 9:16 原生适配；用于亲子关系情感共鸣类内容运营 |

## 二、分段生成方案（每段一个 scene prompt，对应剧本镜头）

文本生成视频模型单段时长有限，按 6 场拆分为 14 段，每段 5–10 秒，覆盖全部 18 个镜头与全部转场设计。生成顺序即段落顺序（S1-1 … S6-2）。

| 段号 | 场次 | 镜头 | 时长 | 画面要点（镜头语言） |
|---|---|---|---|---|
| S1-1 | 第1场 | 镜1+镜2 | 8s | POV 被窝仰视天花板+爸爸掀被子；玩具恐龙视角偷看家庭 |
| S1-2 | 第1场 | 镜3 | 8s | 床底四脚追逃：大脚冲床、小脚抱被躲闪 |
| S1-3 | 第1场→2 | 转场 | 5s | 甩镜（whip pan）到客厅时钟，声音先入的音桥感 |
| S2-1 | 第2场 | 镜4 | 8s | 餐桌上帝俯拍：牛奶、面包、爸爸手机横放盘边（疏离感） |
| S2-2 | 第2场 | 镜5 | 6s | 牛奶杯内视角：透过牛奶往外拍，泛白模糊 |
| S2-3 | 第2场 | 镜6+转场 | 8s | 小宇视角低角度仰拍爸爸（逆光如一座山）；白闪转场 |
| S3-1 | 第3场 | 镜7+镜8 | 8s | 360°环绕+白光大盛；镜像对称：镜中父子身高互换、尖叫 |
| S3-2 | 第3场 | 镜9 | 8s | 快速对切蒙太奇：够柜子失败/看贴纸书发呆 |
| S4-1 | 第4场 | 分屏开场 | 5s | 屏幕裂成左右两块：左学校右公司，平行蒙太奇 |
| S4-2 | 第4场 | 镜10+镜11 | 10s | 左=学校：课桌数学卷子抓耳挠腮、走廊小短腿跑向厕所 |
| S4-3 | 第4场 | 镜12+镜13 | 10s | 右=公司：俯拍办公桌报表/外卖盒、手机消息轰炸 |
| S4-4 | 第4场→5 | 转场 | 5s | 时钟特写+两边时针疯狂旋转，叮停在同一格 |
| S5-1 | 第5场 | 镜14 | 8s | 地铁车窗倒影：父子对面而坐，倒影+真脸双重画面 |
| S5-2 | 第5场 | 镜15+转场 | 8s | 过道低机位：一大一小两只手缓缓靠近握住；逆光剪影+白闪定格 |
| S6-1 | 第6场 | 镜16+镜17 | 8s | 镜子正面定镜回到自己身体；妈妈端饭从背后越肩推近餐桌（与第2场构图呼应） |
| S6-2 | 第6场 | 镜18 | 8s | 片尾彩蛋：电视前父子看动画片，茶几上手机屏幕朝下扣着 |

说明：模型单段视频无法精确承载分屏与人物一致性的逐帧剪辑要求，分段生成后需用剪辑工具（ffmpeg 等）按剧本时序拼接、配音与字幕。当前环境无 ffmpeg，本交付以分段 MP4 + 本方案为准，拼接为后期工序。
