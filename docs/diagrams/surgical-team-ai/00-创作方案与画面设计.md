# 《从人月神话到 AI 外科手术团队》概念图创作方案

需求提出者：用户（基于一段关于康威定律 / 外科手术团队 / AI Agent 时代的论述）
制作执行：媒体艺术家（media-artist-001，dashscope-media-generator Skill → qwen-image-plus 原生 text2image）
验收执行：qwen3-vl-plus 视觉验收（media-vl-skill-001）+ 多模态人工复核

## 一、需求解析（最终方向）

用户先后明确三点要求：
1. 生成**组织架构图**，不要写实场景图片；
2. **不用 Mermaid**（Mermaid 版仅作精确文字对照文档保留）；
3. 用 **AI 图像**生成，**白底、简洁、科技风**。

原始论述的核心叙事弧线（需在图中表达）：
- **康威定律**：沟通结构 ↔ 系统架构互相决定；
- **传统软件团队**：角色多、网状沟通（n(n-1)/2 条路径，成本随人数平方增长，源自《人月神话》）；
- **Brooks 外科手术团队**：设计决策集中到一人（外科医生）脑中，沟通从网状变**星型**，层级减少、成本大降；
- **AI Agent 时代**：1 人 + 一群 Agent ≈ 外科手术团队，决策权集中、执行力放大，瓶颈仍在人类大脑；
- 只有 AGI 到来才可能突破该瓶颈。

## 二、画面设计（白底 · 简洁 · 科技风 · 三段演变）

| 项 | 结论 | 理由 |
|---|---|---|
| 主题 | 组织架构/沟通拓扑的演变：网状 → 星型 → AI 星型 | 忠实覆盖原文三段叙事 |
| 构图 | 横向三联（左→右），蓝色箭头串联，顶部总标题 | 单图表达完整演进 |
| 尺寸 | 1280×720（16:9 横版） | 承载三段并排 |
| 风格 | 白底、扁平矢量、深蓝/青色科技配色 | 用户明确要求"白底简洁科技风" |
| 文字策略 | **最小文字预算**：最终仅保留「总标题 + 三个中央标签」；段小标题由中央标签兼作段名 | qwen-image-plus 对单图中文小字有硬性渲染上限（见下） |

### 画面分段

- **左 · 传统软件团队**：中央「多角色团队」，四周多个无文字小圆点，用密集交错灰色细线连成**网状**；
- **中 · 外科手术团队**：中央「外科医生」，四周无文字小圆点，金色直线**星型**放射；
- **右 · AI 外科手术团队**：中央「人类决策者」（发光大脑图标），四周无文字小圆点，青色直线**星型**放射；
- 四周小圆点不写文字，角色明细以 `组织架构图.md` 精确记录（保持图面极简 + 规避模型文字渲染风险）。

## 三、生成参数与过程记录

- 接口：POST `https://dashscope.aliyuncs.com/api/v1/services/aigc/text2image/image-synthesis`（X-DashScope-Async: enable）
- 模型：`qwen-image-plus`；尺寸：`1280*720`，n=1
- 凭据：`C:\Users\admin\.argo\.env` 的 `QWEN_KEY`（运行时读取，禁止写入文件/日志/提交）
- 迭代：共 11 次生成尝试。发现并确认 **qwen-image-plus 对"标题 + 三段小标题 + 中央标签 + 十余处节点小字"的密集中文文字存在硬性渲染上限**：总标题、段小标题、中央标签通常可渲染；但四周角色小字（如「麻醉师」「AI编码」）几乎必然出现丢字/错字/多画节点，且结果随机。最终采用「最小文字预算」策略，四周节点以无文字圆点呈现，保证关键文字（标题/段标题/中央标签）稳定正确。

## 四、验收方式

qwen3-vl-plus 逐条核对 + 人工复核：① 白底扁平科技风；② 总标题正确；③ 三段 + 左→右箭头；④ 三段小标题；⑤ 网状 / 星型 / AI 星型拓扑对比；⑥ 中央「外科医生」「人类决策者」标签。对模型无法稳定渲染的四周小字，如实记录为已知模型边界，并在 `组织架构图.md` 提供精确角色明细。
