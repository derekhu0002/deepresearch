# 游戏场景永不重复？程序化内容生成正在重塑游戏世界

> 本文结论均来自仓库内洞察报告《洞察：自由生成的游戏——程序化内容生成（PCG）的现状与技术趋势》，关键论断都附原始来源链接。

你有没有想过，玩一个「每次打开都不一样」的游戏？

不是那种「随机刷几个怪」的敷衍，而是**整个世界**——地形、关卡、NPC、剧情——全都在你进入的那一刻，才刚刚被「生成」出来。

这个领域叫**程序化内容生成（Procedural Content Generation, PCG）**。GitHub 上已经有 3,750 个开源仓库在这条路上探索，语言覆盖 C#、Python、Rust、JavaScript 等 15+ 种。我们把它拆成三个维度——**技术栈、内容类型、产品形态**——逐一取证。

## 一、三层技术栈：从数学函数到 AI 驱动

PCG 的技术栈像一个三层蛋糕：

**底层：噪声算法**。Perlin Noise（1983）是奠基之作，FastNoiseLite（3.5k stars）把它封装成了跨 15+ 语言的便携库，OpenSimplex2、Cellular/Voronoi、Value Cubic 等全套算法开箱即用（[github.com/Auburn/FastNoiseLite](https://github.com/Auburn/FastNoiseLite)）。

**中层：约束求解**。如果你给一张像素图，让算法「生成一个看起来像这张图的更大世界」，这就是 WaveFunctionCollapse（25.3k stars）做的事。它把纹理合成问题转化为约束满足问题，用「最小熵启发式」决定下一个要填的格子，通过约束传播确保输出与输入局部一致（[github.com/mxgmn/WaveFunctionCollapse](https://github.com/mxgmn/WaveFunctionCollapse)）。

**上层：AI 驱动**。LLM 和扩散模型正在把 PCG 从「算法生成」推向「理解生成」——游戏不再只是随机生成地形，而是理解叙事并生成与之匹配的内容。

## 二、WFC：一个算法，六款商业游戏

WFC 的厉害之处在于，它已经被至少 6 款商业游戏采用：

- **Bad North** 用它生成岛屿关卡
- **Caves of Qud** 用它多趟生成地牢
- **Townscaper** 将 WFC 与 marching cubes 结合，一键生成城镇
- **The Matrix Awakens** 用它生成城市建筑

WFC 已被移植到 15+ 种编程语言，并集成到 Unity、Unreal Engine 5、Godot 4、Houdini 等主流引擎中。它已经是游戏产业的「标准工具」（[github.com/mxgmn/WaveFunctionCollapse](https://github.com/mxgmn/WaveFunctionCollapse)）。

## 三、从 Roguelike 到开放世界：四种产品形态

PCG 已经跑通了四种商业上成功的产品形态：

1. **Roguelike 地牢探索**：随机生成 + 永久死亡 = 每次不同的体验。Caves of Qud 的开发者 Brian Bucklew 在 GDC 2019 上详细讲述了他们如何用 WFC 结合传统 PCG 方法生成关卡（[github.com/mxgmn/WaveFunctionCollapse](https://github.com/mxgmn/WaveFunctionCollapse)）。

2. **开放世界沙盒**：Minecraft 证明了体素世界的商业可行性，Veloren（7.5k stars）是开源社区对这个范式的 Rust 复刻，受 Dwarf Fortress 和 Cube World 启发（[github.com/veloren/veloren](https://github.com/veloren/veloren)）。

3. **策略模拟**：Dwarf Fortress 的生成式历史早已成为传奇。

4. **AI 原生生成**：这是最新、最激进的方向。

## 四、AI 原生生成：当每个 NPC 都是 LLM Agent

修仙世界模拟器（2k stars，已上架 Epic Games Store）标志着一种全新品类：

> 「模拟器中，每一个修士都是独立的 Agent，可以自由观测环境并做出决策。在规则与 AI 共同编织的世界中，修士 Agent 们与宗门意志相互博弈又合作，新的精彩剧情不断涌现。」

没有预设剧本，没有固定对话树。每个 NPC 都有独立的性格、记忆、人际关系和行为逻辑——他们会结党营私，甚至会逆天改命（[github.com/4thfever/cultivation-world-simulator](https://github.com/4thfever/cultivation-world-simulator)）。

这种「确定性计算 + LLM 叙事」的架构，与金融 Agent 的设计范式高度一致：数字由代码计算，叙述由 LLM 生成，全程可追溯。

## 五、趋势判断：PCG 的三个确定性方向

基于本次取证，我们给出三个判断：

1. **约束求解（WFC）已成为基础设施**。25.3k stars、15+ 语言移植、6 款商业游戏采用——WFC 不是「新奇算法」，而是「标准工具」。

2. **LLM 驱动的涌现式游戏是下一个爆发点**。修仙世界模拟器（2k stars）和 img2threejs（12.3k stars）分别从「叙事生成」和「3D 模型生成」两个方向证明了 AI 驱动 PCG 的可行性。

3. **开源生态正在从「工具」走向「完整游戏」**。Veloren、Cubyz、Pioneer 都在证明，PCG 可以支撑从小型 Roguelike 到开放世界 RPG 的完整产品。
